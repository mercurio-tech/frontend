EcoIrriga: Automação Inteligente de Baixo Custo

Resumo do Projeto

Este projeto propõe uma alternativa acessível para otimizar o uso da água na horta do colégio. Através de sensores de umidade do solo conectados a um microcontrolador de baixo custo, o sistema ativa uma microbomba d'água somente quando necessário. Os alunos desenvolveram também um painel de monitoramento analógico simples para facilitar a leitura da umidade pelos cuidadores das hortas escolares. O experimento demonstrou uma redução de cerca de 30% no desperdício de água em comparação com métodos tradicionais de rega manual.
